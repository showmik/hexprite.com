The dedicated pixel art and font editor for embedded displays.

A native Windows application for embedded graphics. Hexprite provides 1-bit monochrome editing, custom bitmapped fonts, live hardware streaming, and direct C-array source linking without external converters.

Core Capabilities

> Precision Drawing Tools

Everything you need to design pixel-perfect monochrome graphics without the bloat.

  • ■ Essential tools: Pencil, line, rectangle, ellipse, and flood fill.
  • ■ Advanced selection, move, and precise transformation controls.
  • ■ Clean, distraction-free interface focused on pixel manipulation.

> Direct Source Code Sync

Link directly to your project's code files. Automatically update embedded C-arrays while preserving existing file signatures and formatting.

  • ■ Link natively to .c, .h, .cpp, and .py source files.
  • ■ Two-way sync: modify arrays on disk or load sprites from code.
  • ■ Built-in RLE and LZSS compression generation for minimal footprint.

> Embedded Typography

Create custom bitmapped fonts. Import TTF/OTF, adjust kerning, and generate C code for Adafruit GFX, u8g2 BDF, and LVGL.

  • ■ Generate C code for Adafruit GFX, u8g2 BDF, and LVGL formats.
  • ■ Live Flash memory footprint estimation as you design.
  • ■ Pixel-perfect glyph editing with automatic bounding-box cropping.

> Live Hardware Streaming

Stream canvas edits directly to physical microcontrollers over USB/Serial in real-time.

  • ■ Stream canvas edits directly to microcontrollers over USB/Serial.
  • ■ Asynchronous, zero-lag pipeline supporting baud rates over 115200.
  • ■ Built-in Arduino bootloader protection and auto-reset handling.

> Sprite Animation

Create and preview multi-frame animations with timeline management and configurable framerates prior to compilation.

  • ■ Multi-frame timeline management with configurable framerates.
  • ■ Live onion-skinning overlay for previous and next frames.
  • ■ Export as animated bytearrays, 2D C arrays, or sprite sheets.

> Advanced Dithering

Import standard graphics and perfectly convert them to 1-bit monochrome art using multiple dithering techniques.

  • ■ 6+ built-in algorithms including Floyd-Steinberg, Bayer, and Atkinson.
  • ■ Adjustable adaptive thresholding and gamma correction.
  • ■ Real-time preview of dithering results before applying.

> Native Flipper Zero Support

First-class support for the Flipper Zero community. No external python scripts or web converters required.

  • ■ Native read and write support for Flipper Zero .bm (Icon) and .xbm formats.
  • ■ Edit community UI assets directly in the editor without tedious conversion steps.
  • ■ Export ready-to-use graphics for Flipper Zero firmware apps instantly.
