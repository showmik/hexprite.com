Deep dive into the workflow

GIF: Drawing tools in action

> Professional Pixel Editing

Built for speed with a compact 2-point micro-grid UI. True 1-bit data representation means zero ambiguity in your final hardware output.

  • ■ Layers with "Focus Toggle" for visual organization without breaking 1-bit data.
  • ■ Advanced selections: Marching ants & floating selections.
  • ■ Floating Paste Modes: Choose Transparent or Opaque stamping.
  • ■ Hardware-accelerated WPF rendering for zero lag.
Screenshot: Live OLED Simulation

> Built for Target Hardware

Stop guessing what your UI will look like. Hexprite flawlessly simulates monochrome OLEDs, LCDs, and e-paper displays like SSD1306 and SH1106.

  • ■ Strict data structures—no accidental greyscales or anti-aliasing artifacts.
  • ■ Accurate monochromatic display simulation.
  • ■ Smooth zoom/pan controls to inspect every single pixel.
Screenshot: Code Export

> Code Export & Source Linking

Ditch the copy-paste routine. Hexprite can link directly to your project's code files to automatically update C-arrays while preserving your custom signatures.

  • ■ Formats: Adafruit GFX, u8g2, Plain C, MicroPython, and more.
  • ■ Built-in Compression: Integrated RLE and LZSS with C decoders.
  • ■ Source File Linking: Updates your source files natively.
Screenshot: Timeline Panel

> Frame-by-Frame Animation

Bring your sprites to life right inside the editor. Test animations flawlessly before compiling your C code.

  • ■ Intuitive Timeline Panel for frame management.
  • ■ Playback controls with adjustable framerates.
  • ■ Export directly as animated bytearrays or multiple C arrays.
Screenshot: Multi-Tab Interface

> Lightning Fast & Native

Tired of sluggish, bloaty web wrappers? Hexprite is a pure Windows desktop application optimized to get out of your way.

  • ■ Near-instant startup times and minimal RAM usage.
  • ■ Multi-tab workflow: Edit up to 10 files side-by-side.
  • ■ 100% Offline, zero telemetry, no forced accounts.
Screenshot: Font Engine & Flash Estimator

> Embedded Typography Suite

Design custom bitmapped fonts directly for microcontrollers. Import TTF/OTF, adjust kerning, and export ready-to-use C code.

  • ■ Exports to Adafruit GFX, u8g2 BDF, and LVGL formats.
  • ■ Live Flash memory footprint estimation.
  • ■ Pixel-perfect individual glyph editing with tight bounds cropping.
GIF: Live Serial / COM Streaming

> Live Hardware Streaming

Stream canvas edits in real-time to physical microcontroller hardware connected over USB or Serial.

  • ■ Asynchronous non-blocking pipeline for zero drawing lag.
  • ■ Supports max baud rates (115200+).
  • ■ Arduino bootloader auto-protection (DTR serial reset handling).
Screenshot: Flipper Zero / GIF Import

> Flipper Zero & Image Import

Native integration with community standards. Import images or animated GIFs and convert them beautifully to 1-bit monochrome.

  • ■ Native Flipper Zero (.bm / .xbm) read/write support.
  • ■ 6+ dithering algorithms (Floyd-Steinberg, Bayer, etc.).
  • ■ Adaptive thresholding and gamma correction.

Hey fellow dev. I built Hexprite for a simple reason: I was tired of sketching sprites in MS Paint, opening random web converters, praying the output was right, pasting it into my IDE, realizing it was upside down, and starting over.

I needed a proper tool for embedded dev, so I built it. As a solo developer from Bangladesh, this project is a labor of love. The monochrome tools will always be free.
